## 인증 모드 (rhwpweb 의 `RHWP_AUTH`)

| 값 | 동작 |
|---|---|
| `request` | rhwp-auth 로그인 (compose 기본) — Nginx `auth_request`, `RHWP_AUTH_UPSTREAM`(기본 `http://rhwp-auth:8080`) |
| `basic` | Nginx Basic 인증 — `/etc/nginx/auth/.htpasswd` 마운트 필수 (이미지 단독 실행 기본값) |
| `off` | 인증 없음 — 앞단에서 인증할 때만 |

- 로그인하지 않으면 앱 파일(HTML·JS·WASM) 자체를 받을 수 없다.
- 인증 서비스가 내려가 있으면 앱은 열리지 않는다(500, 열리는 쪽으로 실패하지 않음).
- `/healthz`, `/rhwp/manifest.webmanifest`, `/rhwp/icons/`, `/rhwp/sw.js` 는 인증 없이 응답한다.

## rhwp-auth 실행 방식

- root 로 시작해 `/data` 전체와 `/files`·사용자 폴더(최상위만)의 소유자를 PUID:PGID 로 맞춘 뒤 그 사용자로 내려간다.
  `files/mount/*` 안은 건드리지 않는다. compose 에서 `user:` 로 비root 를 지정하면 이 과정을 건너뛴다.
- 필요한 권한만: `cap_drop: ALL` + `CHOWN, SETUID, SETGID, DAC_OVERRIDE, FOWNER` (내려간 뒤에는 모두 사라짐), `read_only`, `no-new-privileges`.
- 이미지의 `/data`·`/files` 기본 소유자는 65532 — 예전 compose(`user: 65532`, 새 볼륨)에서도 시작되도록.
- 시작 로그에 저장 위치 점검 결과(`저장 위치: …`)와 공유 폴더 목록을 남긴다.

## 서비스 워커(PWA)를 끈 이유

업스트림 RHWP 는 서비스 워커로 앱을 오프라인 캐시한다. 그러면 한 번 접속한 브라우저는 **서버에 묻지 않고**
캐시에서 앱을 띄우므로 로그아웃·계정 비활성화가 먹히지 않는다. 그래서 기본 빌드(`RHWP_PWA=0`)는 서비스 워커를
등록하지 않고, 예전 버전이 설치한 서비스 워커는 스스로 캐시를 지우고 해제된다(`web/no-sw/`).

## 편집기 확장 (`web/cloud/cloud.js`)

업스트림 소스를 고치지 않고 `window.rhwpStudio.automation` 확장 API(`registerCommand`, `addMenuItem`)로 붙인다.
업스트림이 그 API 를 바꾸면 자동 반영의 스모크 테스트가 실패해 **그 버전은 배포되지 않는다**.

## 서버 저장 API

세션 쿠키 + `X-RHWP-CSRF` 헤더(`/api/me` 가 알려줌). 경로는 `my/…` 또는 `mount/<이름>/…`.

| 요청 | 내용 |
|---|---|
| `GET /rhwp-auth/api/me` | 사용자 이름, 관리자 여부, csrf |
| `GET /rhwp-auth/api/fs?path=` | 폴더 목록 (`path` 비우면 최상위: 내 문서 + 공유 폴더). 쓰기 가능 여부 포함 |
| `GET /rhwp-auth/api/fs/file?path=` | 파일 받기 (ETag) |
| `PUT /rhwp-auth/api/fs/file?path=` | 저장. `If-Match`(덮어쓰기) / `If-None-Match: *`(새 파일) — 충돌이면 412 |
| `DELETE /rhwp-auth/api/fs/file?path=` | 삭제 (공유 폴더는 관리자만) |

- ETag = mtime(ns) + 크기. 읽기 전용 → 403 "읽기 전용", 권한 없음 → 403, `files/mount` 바로 아래 저장 → 400, `../` → 400.
- 예전 `/rhwp-auth/api/files[/이름]` 은 `my/` 로 계속 동작한다.
- nginx 는 `location ^~ /rhwp-auth/api/` 에서 `client_max_body_size ${RHWP_UPLOAD_MAX_MB}m`.

## 캐시 정책

| 대상 | Cache-Control |
|---|---|
| `/rhwp/assets/*` (해시 파일명) | 1년, immutable |
| `index.html`, `sw.js`, manifest, `rhwp_bg.wasm`, `rhwp.js` 등 | `no-cache` (ETag 재검증) |
| `fonts/`, `icons/`, `images/` | 7일 |
| `/rhwp-auth/*` | `no-store` |

큰 파일은 빌드 시 gzip 으로 미리 압축해 둔다(`gzip_static`).
