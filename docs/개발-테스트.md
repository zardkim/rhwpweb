# 테스트

## Go (rhwp-auth)

Go 가 없어도 컨테이너로 돌릴 수 있다:

```bash
cd auth
docker run --rm -v "$PWD:/src" -w /src -e GOFLAGS=-buildvcs=false golang:1.26-alpine \
  sh -c 'gofmt -l . ; CGO_ENABLED=0 go vet ./... && CGO_ENABLED=0 go test ./...'
```

이름 검사·경로 해석·예약 이름·내 문서·공유 폴더·mountinfo 분류·SQLite 저장소(두 핸들 동시 접근)·users.json 가져오기를 다룬다.
Docker 빌드에서도 `go vet` 이 돈다.

## e2e (Playwright)

스크립트는 `scripts/` 에 있다. 프로젝트 폴더 밖에서 실행한다:

```bash
mkdir -p ~/.cache/rhwp-docker/e2e && cp scripts/cloud-*.mjs ~/.cache/rhwp-docker/e2e/
docker run --rm --network host -u "$(id -u):$(id -g)" -e HOME=/tmp -v ~/.cache/rhwp-docker/e2e:/w -w /w \
  mcr.microsoft.com/playwright:v1.63.0-noble \
  sh -c '[ -d node_modules/playwright ] || npm i -s playwright@1.63.0 >/dev/null; node cloud-e2e.mjs http://127.0.0.1:17780 <사용자> <비밀번호>'
```

| 스크립트 | 인자 | 확인하는 것 |
|---|---|---|
| `cloud-e2e.mjs` | 주소 사용자 비번 | 로그인 → 서버 저장 → Ctrl+S → 충돌 412 → 다시 열기 → 삭제 (`테스트 문서.hwp` 가 남음) |
| `cloud-session-e2e.mjs` | 주소 사용자1 비번1 사용자2 비번2 | 자동 저장·복구·로컬 저장·사용자 전환 연동 |
| `cloud-mobile.mjs` | 주소 사용자 비번 | 휴대폰 화면(터치) |
| `cloud-mount-e2e.mjs` | 주소 관리자 비번 사용자 비번 쓰기공유 읽기전용공유 | 공유 폴더·폴더 탐색·읽기 전용·삭제 권한·계정 메뉴·로그아웃·저장 위치 점검 |

`cloud-mount-e2e.mjs` 준비: 쓰기 공유 안에 `양식/신청서.hwp`, 읽기 전용 공유 안에 `규정.hwp` 를 두고
`docker-compose.override.yml` 로 `/files/mount/<쓰기공유>`, `/files/mount/<읽기전용공유>:ro` 를 붙인다.

## 예전 compose 호환

이미지를 바꿀 때는 예전 compose(볼륨 방식: `rhwp-auth-data:/data`, `${RHWP_FILES:-rhwp-files}:/files`, `user: 65532:65532`)로도 시작되는지,
`scripts/migrate-volumes.sh` 로 옮긴 뒤 새 compose 로 사용자·문서가 그대로인지 확인한다.
